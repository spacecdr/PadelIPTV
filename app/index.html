Impostazioni YouTube

  1. Apri console.cloud.google.com e crea o seleziona un progetto.
  2. In Libreria abilita YouTube Data API v3.
  3. In Credenziali crea una chiave API e limitala a YouTube Data API v3.
  4. Inserisci la tua chiave qui oppure nella sezione YouTube del telecomando web.

La chiave resta sulla TV. Nessun accesso al tuo account YouTube è richiesto. La quota del tuo progetto Google limita gli aggiornamenti.
